# Qingxuan Wang — academic homepage

A buildless, responsive academic homepage inspired by Jon Barron's layout. The publication section uses compact cards with CCF, JCR, and year filters.

## Publish with GitHub Pages

Push these files to the `main` branch. In the repository, open **Settings → Pages → Build and deployment → Deploy from a branch → main → / (root)**. The site URL is https://qingxuan-wang.github.io/.

No Ruby, Node build, or third-party scripts are required. `.nojekyll` enables direct static-file hosting.

## Edit

- `index.html`: biography, links, publication cards, and academic service.
- `style.css`: page and card layout.
- `script.js`: publication filters; the default filter is CCF-A.
- `assets/profile-mystic.png`: generated illustrated profile image.
- `assets/publications.bib`: downloadable bibliography.
- `SOURCES.md`: factual sources and classification decisions.

Preview locally with any static file server, then open the repository root in a browser.
